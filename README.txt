SARTHI BIRTHDAY WEBSITE

Files:
- index.html (website)
- photos/ (the five photos you provided)

HOW TO PUBLISH:
1. Keep index.html and the photos folder together.
2. ZIP the CONTENTS of this folder (index.html and photos folder).
3. Upload the ZIP to a static website host that supports a ZIP containing index.html at the root.
4. Open the public link on another phone to test the photos before sharing it.

IMPORTANT:
The five supplied photos are bundled with the website and will be visible to anyone who has the public link.
The "Add more photos" button is only a reminder/local picker; newly selected photos are not uploaded to the server. To share more photos, add them to the photos folder, add a matching <figure> entry in index.html, then republish.
